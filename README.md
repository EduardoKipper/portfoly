# Portfólio — Eduardo Kipper

Portfólio profissional em React, com versões em português e inglês e conteúdo editável por painel admin.

## Comandos

| Comando             | O que faz                                             |
| ------------------- | ----------------------------------------------------- |
| `npm install`       | Instala as dependências (Node 22.22 ou superior)      |
| `npm run dev`       | Sobe o servidor de desenvolvimento                    |
| `npm run build`     | Verifica tipos e gera a versão de produção em `dist/` |
| `npm run preview`   | Serve a versão gerada localmente                      |
| `npm run lint`      | Roda o oxlint                                         |
| `npm run typecheck` | Verifica os tipos com o TypeScript                    |
| `npm test`          | Roda os testes uma vez (Vitest)                       |
| `npm run format`    | Formata o código com Prettier                         |

## Documentação

A arquitetura e as decisões do projeto ficam em [`docs/`](docs/README.md). Atualize essa pasta sempre que a arquitetura mudar.
